# 同城小程序二手交易同城生活求职招聘相亲交友同城小程序校园同城生活小程序

源码地址：ym7k.com/19326/

## 🧱 技术栈

- 前端：UniApp（uView）｜微信小程序、H5，可选打包 APP
- 后端：FastAdmin / ThinkPHP6 + MySQL + Redis
- 配套：PC 运营后台；可扩展 PC 门户
- 部署环境：PHP7.4–8.1、Nginx、高德 / 腾讯地图、OSS、微信支付、短信

## 📦 四大核心模块（后台自由开关）

✅ **二手交易集市**
发布闲置、数码、家具、书籍、衣物；支持一口价、议价、担保交易、自提 / 邮寄；商品分类、图片视频、收藏、私信沟通、订单、确认收货、交易评价；校园模式侧重教材、电动车、宿舍用品、毕业清仓。

✅ **求职招聘（全职 + 兼职）**

- 同城版：企业入驻，全职、短期零工；简历投递、人才库、岗位置顶
- 校园版：主打校园兼职、寒暑假工、校内勤工俭学、社团招新，简化简历
岗位筛选、报名、隐私拨号、IM 聊天、岗位刷新付费推广

✅ **相亲交友 / 婚恋红娘**
实名 + 人脸核验，资料卡片、择偶条件、标签匹配、附近用户；打招呼、私信、心动、拉黑；红娘后台线索管理、会员解锁联系方式；可开启普通交友搭子，也可开启严肃相亲；校园模式可关闭婚恋，只保留搭子、交友。

✅ **社区圈子动态（校园特色）**
图文 / 短视频动态、表白墙、失物招领、求助、活动招募；点赞评论、话题分类；校园圈子：考研搭子、打球、饭搭子、社团活动；同城圈子：本地活动、探店。

✅ **附加便民（选配）**
顺风车、失物招领、店铺黄页、活动报名、积分签到

## 🙋 用户端（小程序）

- 微信一键登录，实名核验；校园模式可增加学号 / 校园卡审核
- LBS 定位，【城市模式】全城范围 /【校园模式】限定本校地理围栏
- 首页模块化导航，后台拖拽调整入口
- 发布管理、收藏、消息、订单、充值、我的会员、发布记录
- 分享海报，邀请好友裂变

## 🧑‍💼 PC 总运营后台

- 模块总开关：单独关闭相亲、关闭二手、切换【同城 / 校园】模式
- 分类管理：二手类目、岗位分类、交友标签、圈子话题自定义
- 内容审核：帖子、商品、岗位、交友资料、敏感词风控、举报、黑名单
- 变现体系：
  - 二手：商品置顶、加急、交易抽佣、担保服务费
  - 招聘：岗位刷新、置顶套餐
  - 交友：会员解锁私信、查看联系方式、心动次数包、红娘佣金
- 财务：充值订单、流水、提现对账
- 多城市 / 多校区：支持多校区分站、独立管理员、分校区数据隔离
- 数据统计：发布量、浏览、咨询、交易、会员转化报表

## ✨ 版本切换亮点（重点）

1. **双模式一键切换**
   - ✅ **校园模式**：围栏定位、表白墙、教材二手、校内兼职、搭子社交，关闭成人婚恋，适合高校创业
   - ✅ **城市同城模式**：面向社会，相亲婚恋、全城二手、企业招聘、本地便民
2. **社交属性强**：和前面纯分类信息门户最大区别，重点做 UGC 圈子、交友匹配，粘性更高
3. **担保交易闭环**，二手可以走平台担保，降低纠纷
4. **源码无加密，支持深度二开**，可以单独剥离模块，只做校园搭子小程序
